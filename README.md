# Ehsan Rahimi — academic homepage

Personal research homepage, served by GitHub Pages as a single static page (`index.html`).
The publication list is generated from verified data, so adding a paper or refreshing
citation metrics is one command rather than hand-editing HTML.

## Layout

| Path | What it is |
|---|---|
| `index.html` | The website. Generated by `scripts/build.py`; do not edit by hand. |
| `data/publications.json` | One record per paper. The source of truth for the publication list. |
| `data/research_areas.json` | The four research areas and their themes (names, summaries). |
| `data/metrics.json` | Google Scholar citations, h-index, i10-index and citations per year. |
| `templates/index.html` | Page layout, styles, scripts and fixed text (about, teaching, education, contact). |
| `scripts/build.py` | Builds `index.html` from the template and the data. |
| `scripts/update_data.py` | Finds new papers on ORCID, refreshes Scholar metrics, then rebuilds. |
| `ehsan_rahimi.html` | Redirect from the old page address to the homepage. |

Both scripts need only Python 3.8+ (standard library; no packages to install).

## Routine update (new paper or new citations)

```bat
cd ehsan-rahimi.github.io
python scripts\update_data.py
git add -A
git commit -m "Update publications and citation metrics"
git push
```

`update_data.py` lists ORCID journal articles whose DOI is not yet on the page, pulls their
metadata from Crossref (or doi.org for DOIs registered with mEDRA and similar agencies),
asks which research theme each belongs to, updates citation counts from Google Scholar and
rebuilds `index.html`. Options: `--dry-run` (report only), `--no-scholar` (skip Scholar,
e.g. when Google shows a CAPTCHA), `--no-orcid`, `--no-build`.

A paper reaches ORCID automatically when your ORCID record is linked to Crossref
(ORCID → Works → Add → Search & link → Crossref Metadata Search) or when a journal
pushes it there. Papers without a DOI must be added to `data/publications.json` by hand.

## Editing by hand

* **A paper**: edit or add a record in `data/publications.json`, then run
  `python scripts/build.py`. Required fields: `id` (unique), `year`, `title` (plain text;
  `<em>` allowed for species names), `authors`, `journal`, `url` (`https://doi.org/<doi>`
  when there is a DOI), `domain`, `theme`, `citations`, `language` (`en` or `fa`).
  The build stops with a clear message if a record is incomplete or a DOI is duplicated.
* **Research areas or themes**: `data/research_areas.json`.
* **About, teaching, education, contact text**: `templates/index.html`, then rebuild.
* **Portrait**: save a square photo as `assets/profile.jpg` and rebuild; it appears above
  your name.

## Conventions

* Year is the volume year when a paper has been assigned to an issue, otherwise the year
  of first online publication. This matches Google Scholar and ORCID.
* Every DOI was checked against Crossref (or its registration agency) for title, journal
  and year. Papers in Iranian journals without DOIs link to the journal page or to their
  DOR identifier.
* Citation counts come from Google Scholar and are dated on the page.

## Publishing on GitHub Pages

Settings → Pages → Build and deployment → Source: *Deploy from a branch*, Branch: `main`,
folder `/ (root)`. With the repository named `ehsanrahimi666.github.io` the site is served
at `https://ehsanrahimi666.github.io/`; under any other name it is served at
`https://ehsanrahimi666.github.io/<repository-name>/`.
